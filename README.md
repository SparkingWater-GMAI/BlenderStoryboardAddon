# BlenderStoryboardAddon
This is my first development for a blender addon souly using Grok and other LLM
Here is the rough timeline for development for end of 2025 through 2026
This is subject to change

1-Year Roadmap (2026)
Q1 (Jan-Mar): Core Stability & Polish

Bug fixes from user feedback (e.g., more robust UUID handling for animations).
Implement the essentials above (exports, GP, append).
Basic testing with real storyboards (e.g., 20-scene test file).
Release v7.0 as "Stable Foundation".

Q2 (Apr-Jun): Workflow Enhancements

Drag-and-drop reordering in thumbnail browser.
Keyboard shortcuts for all major actions.
Auto-clean on reordering (integrate into Move Up/Down).
Add "Duplicate Scene" feature.

Q3 (Jul-Sep): Collaboration & Sharing

Multi-user notes (collaborative .blend sharing).
Advanced PDF layouts (grid views, arrows for moves).
Animatic improvements (add sound/dialogue playback).
Release v8.0 "Pro Workflow".

Q4 (Oct-Dec): Flashy Expansions

AI-assisted camera suggestions (using Blender addons like CameraCAD).
Cloud sync for thumbnails/metadata.
Integration with sequencer for full animatic editing.
VR preview mode for immersive storyboard review.
Release v9.0 "Advanced Previz".
